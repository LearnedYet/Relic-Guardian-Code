# Relic Guardian

## Project Goal

Build a polished third-person action game demo for my Unity portfolio.

The primary goal is not just to finish a game, but to learn professional Unity development and prepare for Unity internship interviews in China.

---

## Engine

- Unity 6.3 LTS
- Universal Render Pipeline (URP)

---

## Programming Language

- C#

---

## Target Platform

- Windows

---

## Core Gameplay

- Third-person movement
- Camera control
- Jump
- Dodge
- Melee combat
- Hitstop
- Perfect Dodge
- Enemy AI
- Boss battle

---

## Project Principles

- Gameplay first.
- Clean and maintainable code.
- Learn every system before implementing it.
- Build one feature at a time.
- Finish before expanding.
